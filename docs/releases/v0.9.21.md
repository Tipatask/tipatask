## Highlights

- **Agents can now check their work on screen (macOS).** Claude, Codex and Pi task runs can take screenshots, click and type in apps to verify UI changes. In Plan mode they can only look, not act. TipΔTask asks for the Screen Recording and Accessibility permissions this needs at startup. The prompt names only the permissions that are off and offers Open System Settings, Later or Don't Ask Again.
- **Remote control from the web app.** A new **Settings → General → Remote control** switch lets your signed-in account start tasks, including objectives, and drive this project's terminals from the web app. The setting applies to this device only. From the web you can approve plans, allow or deny tool requests, and take keyboard control in Plan, Auto and Bypass modes. Runs started from the web appear in the Task App's active sessions with a globe marker.
- **Discuss any task in one click.** Board cards have a compact chat icon next to Start. It opens the task's chat, and you pick the model in the chat's start panel.
- **Chinese and Spanish interfaces.** Choose 简体中文 or Español in **Settings → General**.
- **Scoped Cowboy-Coding mode.** Choose **Related Tasks Only** or **Whole Project**. Each follow-up task starts in a fresh session. You can also set the scope for many tasks at once from the bulk action bar.

## Improvements

- Parent objectives start like any other task. The agent first researches and prepares the objective, saves subtasks if needed, then runs them one after another.
- With objective grouping off, parent objectives keep their own card and progress on the board alongside their subtasks.
- Sprint headers have a select-all pill that selects every visible card in the sprint, plus a Start action.
- The left menu has a new **My Active Tasks** section listing your in-progress human tasks.
- Bulk agent changes now include a **Model** picker and always save a model the agent actually offers.
- Dependency keys of completed or canceled tasks appear struck through on cards, in task forms and in previews.
- Images in task and project chats now show inline where you inserted them. Pasting or dropping another image keeps your cursor position.
- **Cmd/Ctrl+S** saves and closes the Task Edit modal.
- Saving a task in the edit modal immediately updates its Start button and the Start availability of tasks that depend on it.
- New sprints, and open sprints without dates, get automatically forecast start and end dates.
- Branch and pull request links created by merge publishing are recorded on the task.
- The web app's Model field now suggests the models actually available on your devices.
- The notification **Repair** in Settings now verifies its result. It tells you to eject a mounted installer disk or names the leftover app copies that still block notifications.
- On macOS 13 and newer, startup offers optional guidance for enabling App Management.
- Ukrainian terminology is more consistent across the app.

## Fixes

- Long card titles always start at their first letter and end in an ellipsis instead of scrolling away on hover.
- Codex tasks without an explicit model no longer try to run a model Codex has retired.
- Focusing or expanding a card no longer locks board scrolling.
- Projects set up before device tracking now connect to the web app correctly, and runs are attributed to the right machine.
- A task left claimed by a device after the app quit or crashed is released automatically, so other devices can run it again.
- Typing into a web-controlled terminal no longer loses control to the desktop because of terminal background signals.
- Signing out or switching accounts immediately ends remote access for the previous account.
- Projects without Git no longer produce repeated merge-status errors.
- The Open Project chooser stays usable when a task modal is open.
- Completed sessions keep their green check in the active sessions list.
- Card action menus and controls close properly when the cursor leaves after a click.
- Task urgency is preserved when tasks are created or updated by agents.
- The browser login form works again.

## Upgrade notes

- If you had enabled remote control before this release by editing a project's config, it is now off until you turn on **Allow remote control** in Settings on each device.
- Tasks that previously had Cowboy-Coding mode turned on now use the **Whole Project** scope.
