## Highlights

- Cowboy chaining now follows your current settings when a task finishes, not the settings it started with. Turn Cowboy on, change its scope, or switch permission mode while a task is running, and the next tasks start (or don't) based on what's set at completion.
- After every finished task, the agent reports what happened with the chain: which tasks it started, or why none were started.

## Improvements

- Tasks launched with Cowboy off, or in Plan or Auto mode, can still hand off to the next task if Cowboy is turned on before they finish. The chain picks up from the finished task's sprint and position.
- Claude, Codex and Pi agents now get consistent instructions for chaining. They check the completion outcome, retry once only when the chain service is briefly unavailable, and state the result in their final reply.
- Finishing a task always saves the completion, even if starting the next tasks is refused or fails.

## Fixes

- Opening Settings while a task chat or project chat window is open now shows Settings on top instead of hidden behind the chat.
- Pressing Escape with Settings open over a chat window now closes only Settings. Previously it closed the chat too.
- The orange "Resolution" label on comments in the task editor's Comments tab is readable again in all themes. Its text had been drawn in faint grey on the orange background.
