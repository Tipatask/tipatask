## Highlights

- **Brand colors as window accents:** pick up to three brand colors for a project, and the Task App window uses them as its accent colors.
- **Attachments shown where you reference them:** images appear on their own line and files appear as inline chips in task descriptions, board cards, comments and chat messages.
- **Attachment strip while you type:** every text box that accepts images and files now shows them in a strip underneath as you edit.
- **Full-window file preview in chat:** opening a file from the task or project chat window now uses the whole window, with the chat in a slim column on the left.
- **Sprint order switch on the board:** switch between Oldest first and Newest first directly from the Board and List tabs.

## Improvements

- **Brand colors:** the brand color setting is now a list of up to three colors, marked Primary and Secondary. No color is selected by default. Without brand colors, the window keeps the theme's accent colors. You can set them in Settings > General and in the setup wizards.
- **Project identity settings:** Settings > General has a cleaner identity section:
  - One project mark shows the logo, or the initials on the brand color.
  - Initials, Brand colors and Project logo each have their own row.
  - A "Choose image" button and a "Remove logo" option manage the logo.
  - Only the fields you changed are saved.
- **Project policy dialog:** locked settings are now listed in a Policy row. That row opens a dedicated dialog where the project owner can review and edit the project's rules. Company rules still take precedence.
- **Attachments in text:**
  - Images always start on a new line, even when written mid-sentence.
  - Uploaded files and project artifacts appear as compact chips with an icon and file name.
  - Descriptions, comments and chat messages now display attachments the same way.
- **Attachment strip:** the strip appears under the New Objective composer, the chat composer, New Task, and the Task Edit description and comment boxes.
  - Images still uploading appear as dimmed placeholders.
  - Hovering over a reference in the text highlights its tile.
  - Removing a tile removes that attachment from the text, and undo brings it back.
- **Chat file preview:** documents now have room for long lines. Closing the last preview tab restores the regular chat window.
- **Sprint order:** your choice applies immediately and is saved for the project, and the web app shows the same order. If saving fails, the board returns to the previous order and shows an error. The switch only appears when sprints are on and the order would actually change what you see.
- **Who can edit a task:** the board card status menu, the bulk action bar and the Task Edit dialog now follow the same rule. A task can be changed by:
  - its creator
  - its assignee
  - the project owner
  - a member whose role ranks above the assignee's

  Tasks you can only view are clearly marked, and bulk changes skip them and tell you which ones were skipped. Creators, owners and higher-ranked members are no longer wrongly locked out of the edit dialog.
- **New Objective, simpler start:** the guide cards and examples now open from a (?) help button next to History, so the composer gets the full height of the empty view.
- **New Objective progress:** the four-step progress card is replaced by one slim status line. It shows the current stage, a step counter and a short message.
- **Proposal cards:** the "Included" label no longer appears on every card. A label now appears only when a card is Rejected or Saving. Pressing Reject again now puts the card back into the save.
- **Translations:** the board's filter bar is now translated in Ukrainian, Chinese and Spanish. This covers the tag filter, search box, Clear button and refresh button. The search field resizes to fit the translated text.

## Fixes

- Accept and Reject on New Objective proposal cards are clickable again. Previously, the card could expand on hover and move the buttons away from the pointer.
- Trying to change a task you aren't allowed to edit no longer disconnects your whole session. The change is refused and you stay signed in.
