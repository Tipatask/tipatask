## Highlights

- **Create without leaving the board.** The left menu's Create item now opens a small menu with New Objective and New Task. Either one opens in a dialog over the board, so your scroll position, filters and selection stay as they were.
- **Guided New Objective.** A progress line shows where a plan stands (Planning, Proposals ready, Saving, Saved) and what to do next. An empty objective offers a short guide with examples, and each proposed task has clear Accept and Reject controls.
- **File previews beside the chat.** File references in task and project chat replies open in a resizable, tabbed drawer next to the conversation. It previews text, Markdown, images and PDFs, and can jump to a specific line.
- **Work presets for projects.** When you create a project, you choose one or more of eight presets: Software, Science, Marketing, Sales, Finance, Health, Home and Personal Growth. Each preset gives agents its own planning and execution guidance, deliverables and checks.
- **Attachments in more places.** The attachment control, now labelled File, is available in New Task and in the Task Edit description. It accepts several files at once and more source and document types.

## Improvements

- Chat replies now show the agent's progress notes, its tool calls and its final answer as separate blocks in reading order. A new Copy answer button copies the answer alone.
- Agents can publish task outputs as project artifacts with named revisions, and you can attach a pinned artifact to a later task or message from the File menu.
- The setup wizard keeps one panel size on every step and shows the current step's name and count. The agent picker is redesigned with aligned rows, enable switches and a clear Default marker.
- Setup shows company or project owner requirements before you choose a device and agents, and repeats them at confirmation. You can set a project logo, initials and brand colour, and Settings shows where enforced values come from.
- Error messages now stay on screen for 30 seconds with a visible countdown. The countdown pauses on hover or focus, and Close dismisses the message at once.
- Plain-text web addresses in task terminals and the objective console are now clickable links.
- Codex plans objectives around what each task needs and hands over, so dependent tasks land in later sprints and small changes keep their verification on the same card.
- Agents can set, change and clear task severity through the task tools.
- Attachments are checked against the supported file types before upload, and AVIF and BMP images are accepted.
- Live chat sessions are tied to the project, server and account they started in. Signing in as a different user ends the previous user's chats, and signing back in as the same account restores chats that are still live.
- The README has a getting-started guide for the installed app, from opening a project to running a first task. The Linux AppImage row now states its x64 and glibc 2.35+ requirements.

## Fixes

- Confirmed terminal links now open in your default browser instead of failing with "Could not open the link". The same fix restores opening attachments, the debug log Reveal button and the macOS Notifications Settings button.
- The board no longer hides Load Earlier Batches for the rest of the session after one reply reported nothing older.
- The bulk action bar no longer slides under the left menu or splits awkwardly in narrower windows.
- The merge panel again tells a pre-existing test failure from a new one in projects that run tests on Node 23 or newer, so one already-failing test no longer blocks a merge.
- With the description editor closed, several attachments added to a task description at once each go on their own line.
