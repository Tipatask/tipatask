## Highlights

- **Work presets for projects.** New projects choose one or more of eight work presets: Software, Science, Marketing, Sales, Finance, Health, Home and Personal Growth. Each preset has its own project guides, planning and task workflows, deliverables and checks. Existing projects keep the Software workflow.
- **Create without leaving the board.** The Create item in the left menu now opens a small menu with New Objective and New Task. Either one opens in a dialog over the board, so the board keeps its scroll position, selection and filters.
- **File previews beside the chat.** File references in task and project chat replies open in a tabbed, resizable drawer next to the conversation. It shows read-only previews of text, Markdown, images and PDFs, and can jump to a referenced line.
- **Attachments in more places.** The attachment control (now labelled File) is available in New Task and in the Task Edit description, as well as the chat composers. You can pick several files at once or drop them onto the description.
- **Project artifacts.** Agents can publish task outputs as project artifacts with named revisions. You can attach an artifact to a task or message from the File menu to reuse it in later work.

## Improvements

- New Objective now guides you through a run. It shows a progress line (Planning, Proposals ready, Saving, Saved), an empty state with example goals, and Accept and Reject controls on each proposed task.
- Chat replies now show the agent's progress notes, its tool calls and its final answer as separate blocks in reading order. A new Copy answer button copies the answer alone.
- The setup wizard keeps one panel size on every step and names the current step with a "Step n of N" count. Its steps share a more consistent layout that stays readable in dark themes.
- The agent picker in setup shows aligned cards with an enable switch and a Default pill, and has better keyboard focus handling.
- Setup shows company or project owner policies before you choose a device and agents, and again at confirmation.
- Projects can have a logo, initials and a brand colour. These appear in the sidebar, and authorized members can edit them in Settings.
- Plain-text web addresses in task terminals and the objective console are now clickable links.
- Error toasts stay visible for 30 seconds with a countdown. Hovering or focusing the Close button pauses the countdown, and Close dismisses the toast immediately.
- Attachments are checked for supported file types before upload. AVIF and BMP images are now accepted.
- Agents receive attached source files with their original extension where it is supported.
- Codex objective planning reads the relevant sources first and splits work around deliverables and handoffs. Small self-contained changes stay on one card.
- The task tools available to agents can now read, set and clear a task's severity.
- Live chat sessions are tied to their project, server and account. When a different user signs in, the previous user's chats are closed.
- The README now includes a short demo, a first-task walkthrough for the installed app and clearer Linux requirements (x64, glibc 2.35 or newer).

## Fixes

- Confirmed terminal links now open in your default browser instead of showing "Could not open the link".
- The same fix restores opening attachments, the debug log Reveal button and the macOS Notifications Settings button.
- "Load Earlier Batches" no longer stays hidden for the rest of a session after the board has once reported nothing older to load.
- The bulk action bar no longer slides under the left menu or wraps awkwardly in narrower windows.
- The merge panel again tells a pre-existing test failure from a new one in projects that run their tests on Node 23 or newer. Before, a project with an already failing test could not merge.
- Several attachments added at once to a closed Task Edit description now each go on their own line.
- Saving or starting a task now waits for attachments that are still uploading, so an unfinished upload is never saved into the description.
