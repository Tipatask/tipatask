## Highlights

- **Work presets for projects.** New projects choose one or more of eight presets: Software, Science, Marketing, Sales, Finance, Health, Home and Personal Growth. Each preset gives agents its own guides, workflows, deliverables and checks. Existing projects keep the Software workflow.
- **Create without leaving the board.** The left menu's Create item now opens a small menu with New Objective and New Task. Either one opens in a dialog over the board, so your scroll position, selection and filters stay as they were.
- **A guided New Objective.** A progress line shows where a run stands (Planning, Proposals ready, Saving, Saved) and what to do next. An empty objective explains the steps and offers example briefs. Each proposed task has clear Accept and Reject controls, and a save bar shows how many are ready.
- **File previews beside the chat.** File references in task and project chat replies open in a resizable, tabbed drawer next to the conversation. It previews Markdown, text, images and PDFs, and can jump to a referenced line.
- **Clearer chat replies.** An agent's progress notes, its tool calls and its final answer now appear as separate blocks in reading order. A new Copy answer button copies the answer alone.

## Improvements

- **Attachments in task descriptions.** The Task Edit description now accepts images and files through the same Embed control as the chat composers, including drag and drop and image paste. Saving and starting wait for uploads to finish.
- **Several files at once.** The Embed pickers let you select multiple images or files in one go, in the objective chat, task and project chats, and the task description.
- **Reusable task outputs.** Agents can publish their outputs as versioned project artifacts. You can pin a specific revision to another task through the Embed menu, which shows each artifact's name, revision, type and size.
- **Project identity and policies.** The setup wizards show any company or project owner requirements before you choose a device and agents, and again at confirmation. You can give a project a logo, initials and a brand color, which appear in the sidebar. Settings shows where enforced values come from and lets authorized members edit shared branding.
- **Tidier setup wizard.** The wizard keeps one panel size on every step, and names and counts the current step beside the progress dots. All steps share one layout, with styling that stays visible in dark themes.
- **Redesigned agent picker.** Agent and model cards line up in one list, with an enable switch and a clear Default pill on each.
- **Error messages stay longer.** Error toasts now remain for 30 seconds with a visible countdown. Hovering or focusing the toast pauses it, and a Close button dismisses it at once.
- **Clickable terminal links.** Plain web addresses printed in task terminals and the objective console are now links.
- **Better Codex planning.** Codex reads the relevant sources before planning an objective. It splits work around deliverables and handoffs, and keeps routine verification on the same task as the change.
- **Severity in task tools.** Agents can now set, clear and read a task's severity through the task tools.
- **Getting started guide.** The README now walks through opening a project and running a first task in the installed app. It also states the Linux AppImage requirements (x64, glibc 2.35+) and links to the Claude and Codex setup guides.

## Fixes

- Confirmed terminal links now open in your default browser instead of failing with "Could not open the link". The same fix restores opening attachments, the debug log's Reveal button and the macOS Notifications Settings button.
- "Load Earlier Batches" no longer stays hidden for the rest of a session after the board once reported nothing older.
- The bulk action bar no longer slides under the left menu on narrower windows, and its controls wrap as whole groups.
- Live chat sessions are now tied to their project, server and account. Signing in as a different user ends the previous user's chats, and the session list refreshes when you refresh the board or reconnect.
