## Highlights

- **Separate Open Project and Create Project.** The Project menu and Get Started screen now have two entries. **Open Project…** (Cmd/Ctrl+Shift+O) opens a folder and gets you working right away. **Create Project…** (Cmd/Ctrl+Shift+N) lets you pick a starter preset first.
- **New "Compose the knowledge base as you go" preset.** It is now option A in the project wizard. The board starts empty with no setup tasks, and each coding task maps the code it touches and adds what it learns to the knowledge base. Projects opened with Open Project use this mode automatically.
- **A first-open prompt for new projects.** The first time a newly created project opens, the app offers to start a **New Objective** or a **Project Discussion**. You can also dismiss it. It appears only once.
- **Set agent, effort and permission mode in bulk.** In the bulk action bar, the Claude Code and Codex entries open an Effort flyout (Agent default, Low, Medium, High, Max), so one pick sets both. A new Permission mode control applies Project Default, Plan, Auto or Bypass to all selected tasks.
- **Notifications are no longer silently lost.** When macOS blocks native notifications, alerts now appear in the always-on-top banner instead.

## Improvements

- Bulk Cowboy-Coding mode now appears only when you choose Bypass as the permission mode. Both settings are saved together when you apply.
- Settings ▸ Notifications has a new **Show on top of other apps** switch. It stays in sync with the View menu and the banner's own Show box.
- The Settings hint about duplicate copies of the app now reads naturally, with proper singular and plural wording.
- Links in terminal output can be opened in your default browser or mail app after you confirm a prompt.
- Running sessions in the left navigation are now listed in the order they started, instead of jumping around.
- Codex objective, task and project chats are limited to their intended tools. Account-connected apps and plugins no longer leak into them.
- Codex text generation that should use no tools now runs without any connected tool servers.
- Urgent maintenance work proposed by the planner now stays in the current sprint instead of drifting to the backlog. Explicit requests for a specific sprint or the Backlog are respected.

## Fixes

- Copy buttons in task and project chats work again in the desktop app. Previously every copy failed with a "Could not copy to the clipboard" message.
- When you reopen a task chat, the message box now grows back to fit your saved draft instead of staying one line tall.
- Codex New Objective chats can read your project's source files again.
- Bulk Cowboy-Coding controls now take the project's default permission mode into account, so tasks that inherit Bypass can be enabled correctly.
