## Highlights

- **Reply to comments.** Every comment in a task now has a Reply button. It starts your reply with a quote of the original comment and a mention of its author. Any text you had already typed is kept.
- **More room for comments.** On the Comments and Notifications tabs, the task description now shrinks to three lines, with a Show description / Hide description toggle. Long comments are shortened with a Show more / Show less toggle.
- **Always-on-top notifications switch is easier to find.** The switch in Settings now appears immediately and is always usable.

## Improvements

- Quoted text in replies appears as a single collapsed line with a Show quote / Hide quote toggle. Your choice stays in place while the comment list refreshes.
- Clicking Reply again replaces the earlier quote instead of adding a second one.
- Long comments no longer scroll inside their own box.
- Tables in comments keep whole words in each cell and scroll sideways instead of squeezing their columns.
- Clicking the shortened description still opens the full-size editor. The General tab always shows the full description.
- The "Show on top of other apps" setting is now called "Always-on-top notifications" and has a shorter hint: when it is off, alerts use system notifications.
- New labels are translated into English, Ukrainian, Chinese and Spanish.

## Fixes

- Comments posted automatically when an agent finishes no longer end with a stray line of hidden marker text.
- Turning off the notification banner now keeps it off. Previously, if macOS blocked system notifications, the banner came back on the next alert even though its "Show" box was unchecked. Now, when always-on-top notifications are off, alerts go only to system notifications. If macOS does not deliver an alert, it stays as a card inside the project window.
- In Settings, the always-on-top notifications switch could stay hidden for several seconds, sometimes much longer, while the app checked notification health. It could also appear disabled. Both problems are fixed.
