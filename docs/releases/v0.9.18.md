## Highlights

- **Export and import projects.** Project ▸ Export… saves the open project as a single `.zip` with its knowledge base and every task that isn't closed, plus the sprints, tags and statuses those tasks use. Project ▸ Import… turns that archive into a new project: you name it and pick its folder and agents. Archives are checked before anything is written, existing files in the folder are kept, and a failed import cleans up after itself so you can try again.
- **Change a running task's permission mode live.** The terminal header now has a permission-mode selector. You can move a run from Plan to Auto or Bypass, or between Auto and Bypass, without restarting it, on Claude, Codex and Pi (Pi 0.84.1 or later). The header shows "Switching to…" until the agent confirms the change and tells you plainly when a switch can't be applied. Claude's Auto mode now uses Claude Code's own auto mode when it's available, and falls back to accepting project edits when it isn't.
- **Cowboy coding chains.** Task Edit has a new Cowboy-coding checkbox, shown while the task runs in Bypass. When such a task finishes, the agent starts the next tasks automatically: every task that depended on it and is now unblocked, or otherwise the next task in the same sprint.
- **"Thank You" voice mode.** Settings ▸ Voice has a new Mode option. In Thank You mode you dictate freely and finish by saying "thank you" (or «дякую» in Ukrainian). The whole dictation is then cleaned of filler words, false starts and pause artifacts and inserted in one go. A "thank you" in the middle of a sentence doesn't end the recording. Standard mode works as before.
- **New recording widget.** While you record, a card at the bottom center shows a timer, a live waveform that follows your voice, and a Stop button that ends every active recording.

## Improvements

- The board's bulk action bar now stages your changes. Move to, Status, Agent and Assignee are saved only when you click **Apply**. **Reset**, or closing the bar, discards them. When the staged agent is Claude, a Design mode toggle appears next to the agent picker.
- On macOS, the first launch explains and then asks once for notification, microphone and folder access (Desktop, Documents, Downloads and your open projects), so an agent never stalls mid-task on a system prompt. You can change these later in System Settings.
- Task and project chat replies have Copy buttons: one on each code block and one on every message.
- New chats appear in the left menu as soon as they start, without reopening the task.
- The Settings dialog has a cleaner, consistent layout across all tabs, with titled sections, aligned labels and controls, and switches for checkboxes. It keeps the same size when you switch tabs, so the tab strip no longer jumps around.
- The New Task Preview now shows the same card as the board. The title wraps properly, nothing gets clipped, and the sprint label reads correctly.
- Avatar, effort and agent badges on board cards and chat preview cards no longer cover tags, descriptions or status pills.
- Status names, Settings ▸ Workflow status names and dropdown arrows are now readable in every theme, light and dark.
- Dropdown arrows stay visible in Windows high-contrast themes.
- Finished or canceled tasks no longer raise idle notifications.

## Fixes

- Fixed task and project chats that could sit on "Agent …" forever. Every turn now ends or shows its error, Stop frees the chat immediately, and Start Chat no longer reopens a broken chat.
- Codex chats now recover after a model-capacity or API error, so you can send another message instead of being stuck.
- Replying to a Codex plan with feedback no longer counts as approval. Later revised plans are announced and can be approved as expected.
- Saving from the New Task Preview or accepting chat proposals no longer overwrites changes someone else made to those tasks in the meantime.
- Saving a new task with no agent selected no longer fails.
- Clicking the agent badge on the pinned Discuss card in an objective chat now opens the task read-only instead of the agent assignment dialog.
