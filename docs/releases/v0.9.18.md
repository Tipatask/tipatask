## Highlights

- **Project Export and Import.** Use **Project ▸ Export…** to save a project's knowledge base and all of its open tasks, along with their sprints, tags and statuses, as a single .zip file. **Project ▸ Import…** turns that file into a new project. A short wizard lets you name the project and choose its folder and agents. Files already in the folder are kept. If an import fails partway, the half-created project is removed so you can try again.
- **Change a running agent's permission mode.** The task terminal header now has a permission-mode selector. You can move a running Claude, Codex or Pi task from Plan to Auto or Bypass, or between Auto and Bypass, without restarting it. The header shows the new mode only after the agent confirms it. For Claude, Auto now uses Claude Code's own auto mode when it is available.
- **Cowboy coding chains.** When a task's permission mode is Bypass, Task Edit offers a new Cowboy-coding checkbox. When a cowboy task finishes, the app starts the next tasks on its own: the tasks that depend on it, or otherwise one more task from the same sprint. They run with the same agent and model as the finished task. Completing the task is enough to start the chain, and the result explains why any candidate task was skipped.
- **Thank You voice mode.** Go to Settings ▸ Voice ▸ Mode and choose Thank You. You can then dictate as long as you like and finish by saying "thank you" (or "дякую" in Ukrainian). The app removes filler words and false starts from the transcript and inserts it once. A "thank you" in the middle of a sentence doesn't end the recording.
- **More agents at once.** The default limit on simultaneous agent sessions is much higher, especially on laptops. For example, a 16 GB Mac now allows 14 sessions instead of 1. A project's own session limit can now raise this number as well as lower it. Memory-based throttling also blocks new sessions only when memory is actually running short.

## Improvements

- Voice recording now shows a widget at the bottom center of the window. It has a timer, a live waveform that follows your voice, and a Stop button that ends every active recording.
- Changes in the board's bulk action bar are no longer saved immediately. **Apply** saves all your changes to the selected tasks at once, and **Reset** discards them. When the chosen agent is Claude, a Design mode toggle appears next to the agent picker.
- Task and project chat replies now have Copy buttons for each code block and for the whole message.
- A new task or project chat now appears in the left menu as soon as it starts, without reopening anything.
- The Settings dialog has a consistent layout across all tabs and stays the same size when you switch between them.
- On macOS, the app explains and then asks once at first launch for notification, microphone and folder access (Desktop, Documents, Downloads and your open projects). Agents no longer stall mid-task waiting on a system prompt. You can change these permissions later in System Settings.
- Status names are easier to read on the board, in Task Edit and in Settings ▸ Workflow, especially on light themes.
- Dropdown arrows now follow the theme's text colour. They also stay visible in Windows high-contrast themes on status pills, board filters, sprint selects and Settings.
- The New Task Preview now looks like a real board card. Long titles no longer overlap the description, and the last line is no longer cut off.
- Avatar, effort and agent badges no longer cover tags, descriptions or status on board cards, chat task cards and the pinned Discuss card.
- Terminals for completed or canceled tasks no longer send "agent is idle" notifications.

## Fixes

- Task and project chats no longer get stuck on "Agent …". Stop now ends a turn right away, and a failed turn always ends with a visible error. Start Chat no longer reopens a broken chat. Codex chats also recover after a "model at capacity" error.
- Saving chat proposals, accepting a card or confirming a New Task Preview no longer overwrites changes someone else made to the same task at the same time.
- Confirming a new task with no agent selected no longer fails with an "Invalid agent_assignee" error.
- Short feedback on a Codex plan, such as "Yes, simplify step 2", is no longer treated as approval, and each new plan is announced as ready.
- Clicking the agent badge on the pinned Discuss card now opens the task read-only instead of the agent assignment dialog.
- The sprint name in the New Task Preview no longer repeats itself (for example, "Sprint: Sprint 412").
