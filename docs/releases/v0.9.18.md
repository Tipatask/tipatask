## Highlights

- **Export and import projects.** Project ▸ Export… saves the open project as a single .zip. The archive holds its knowledge base and every task that isn't closed, plus the sprints, tags and statuses those tasks use. Project ▸ Import… turns that .zip into a new project through a short wizard where you choose the name, folder and agents. Files already in the folder are kept. If an import fails partway, the half-created project is removed so you can try again.
- **Change permission mode while a task runs.** The terminal header now has a permission-mode selector for Claude, Codex and Pi runs. A run that starts in Plan can move to Auto or Bypass, and a run can switch between Auto and Bypass without restarting. The header shows the mode as "switching" until the agent confirms it. If the agent can't switch, the header explains why.
- **Cowboy coding chains.** Task Edit has a new Cowboy-coding checkbox, shown when the task runs in Bypass. When such a task completes, the app starts the next tasks automatically. It first picks tasks that depend on the finished one and are otherwise unblocked. If none qualify, it picks the next eligible task in the same sprint.
- **"Thank You" voice mode.** Settings ▸ Voice ▸ Mode lets you choose between Standard and Thank You. In Thank You mode you dictate freely and finish by saying "thank you" (or "дякую" in Ukrainian). The app then tidies the transcript (filler words, false starts, punctuation) and inserts it in one go.
- **Bulk edits now wait for Apply.** In the board's bulk action bar, changes to Move to, Status, Agent and Assignee are staged until you click Apply. Reset or closing the bar discards them. When the staged agent is Claude, a Design mode toggle appears next to it.

## Improvements

- New recording widget at the bottom centre of the window. It shows a timer, a live waveform that follows your voice and a Stop button. It no longer covers composers, notifications or terminal prompts.
- Claude tasks in Auto now use Claude Code's native auto mode when your CLI and account allow it. Otherwise they fall back to accepting project edits.
- Pi 0.84.1 and later applies the permission gate in every mode, so Plan, Auto and Bypass are enforced and can be switched live.
- Task and project chats have Copy buttons:
  - one on every code block;
  - one on every message, which copies the whole message.
- A newly started chat appears in the left menu right away. You no longer need to reopen the task.
- The Settings dialog has a redesigned layout:
  - every tab uses the same sections and rows;
  - checkboxes are now switches;
  - the dialog keeps one size when you switch tabs, and only the content scrolls.
- On macOS, the first launch explains which permissions the app needs and then asks once for notifications, microphone and folder access. This means an agent no longer stalls mid-task on a system prompt. You can change these later in System Settings.
- The New Task Preview now shows the same card as the board. The title wraps cleanly and long content is no longer clipped.
- Status names and dropdown arrows are easier to read:
  - status names in pills and in Settings ▸ Workflow are readable in every theme, light and dark;
  - dropdown arrows now follow the theme colours;
  - Windows high-contrast themes show dropdown arrows again.

## Fixes

- Closed or canceled tasks with a terminal still open no longer trigger "idle" attention alerts. Real prompts still notify you.
- Avatar, effort and agent badges no longer sit on top of tags, descriptions or status pills. This applies to board cards, chat task cards and the pinned Discuss card.
- Clicking the agent badge on the pinned Discuss card opens the task read-only instead of the agent assignment dialog.
- Saving from the New Task Preview or an objective chat no longer overwrites changes made to the same task elsewhere in the meantime.
- New Task Preview and Confirm no longer fail when no agent is picked.
- The New Task Preview no longer shows "Sprint: Sprint 412"-style labels, and its NEW label no longer overlaps the title.
- Codex chats recover after a model-capacity error, so you can send another message without reopening the chat.
- A short feedback reply to a Codex plan (for example "Yes, simplify step 2") is no longer treated as approval. Later plans are announced as ready to approve.
