## Highlights

- **Project Export and Import.** Use Project ▸ Export… to save a project as one `.zip`. It holds the knowledge base and every open task, along with their sprints, tags and statuses. Project ▸ Import… turns that archive into a new project. A short wizard asks for the project name, folder and agents. Files already in the folder are kept. If an import fails partway, the half-created project is removed so you can try again.
- **Change permission mode while a task runs.** The terminal header now has a permission-mode selector for Claude, Codex and Pi tasks. You can move from Plan to Auto or Bypass, or between Auto and Bypass, without restarting the run. The new mode takes effect only once the agent confirms it. For Claude, Auto now uses Claude Code's own auto mode when it is available.
- **Cowboy coding chains.** Task Edit has a new Cowboy-coding checkbox, shown when the task runs in Bypass. When such a task completes, the app starts the next tasks on its own. It picks the tasks that depend on the finished one, or else the next open task in the same sprint. The next tasks use the agent and model of the run that finished. When a task is not started, the app reports why.
- **Thank You voice mode.** Settings ▸ Voice has a new Mode option. In Thank You mode you dictate freely and finish by saying "thank you" (or "дякую" in Ukrainian projects). The whole transcript is cleaned of filler words and false starts, then inserted once.
- **More agents at once.** The default limit on concurrent agent sessions is now much higher and based on your hardware; for example, 14 on a 16 GB / 8-CPU machine instead of 1. A project setting can now raise the limit as well as lower it. Memory-aware start modes now block new sessions only when memory actually runs short.

## Improvements

- **Voice recording widget.** It now sits at the bottom center and shows:
  - a timer
  - a live waveform that follows your voice
  - a Stop button that ends all active recordings
- **Bulk action bar.** Changes are now staged until you click Apply, and Reset discards them. When the chosen agent is Claude, a Design mode toggle appears.
- **Copy buttons in chats.** Each code block in a task or project chat reply has a Copy button. Each message has a hover Copy action.
- **Live chat list.** The left menu now updates as soon as a chat starts or changes, without reopening the task.
- **Redesigned Settings.**
  - Every tab uses the same layout of sections and rows.
  - Checkboxes are now switches.
  - The dialog keeps the same size when you switch tabs.
- **macOS permissions at startup.** On first launch the app explains, then asks once, for these permissions:
  - notifications
  - microphone
  - access to Desktop, Documents, Downloads and your open projects

  This way an agent no longer stalls mid-task on a system prompt.
- **New Task Preview.** The preview card now matches the board's cards. Long titles wrap cleanly, the last line is no longer cut off, and the sprint label reads correctly.
- **Readable colors.**
  - Status pills and Settings ▸ Workflow status names are easier to read in every light and dark theme.
  - Dropdown arrows follow the theme's text color.
  - Dropdown arrows stay visible in Windows high-contrast themes.
- **Fewer idle notifications.** You no longer get idle notifications for tasks that are already completed or canceled.

## Fixes

- **Stuck chats.** Task and project chats no longer get stuck on "Agent …". A failed turn now always ends visibly, and Stop frees the chat right away. Codex chats recover after model capacity errors, so you can send another message.
- **Codex plan replies.** Short revision replies to a Codex plan, such as "Yes, simplify step 2", are no longer treated as approval. Later plans in the same run are now announced properly.
- **Concurrent edits.** Saving from New Task Preview or accepting chat proposals no longer overwrites changes someone made to the same tasks in the meantime.
- **Tasks without an agent.** Saving a new task with no agent selected no longer fails.
- **Card badges.** On board cards, the avatar, effort and agent badges no longer cover the card's last line. On chat preview cards, these badges now sit at the end of the details row.
- **Pinned Discuss card.** Clicking the agent badge on the pinned Discuss card now opens the task read-only instead of the agent assignment dialog.
