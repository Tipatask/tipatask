## Highlights

- **Computer use for agents (macOS).** Claude, Codex and Pi task runs can now take screenshots, click and type in apps to check their own UI changes. In Plan mode agents can only look at the screen; actions are allowed in Auto and Bypass.
- **Remote control from the web app.** A new **Allow remote control** switch in Project Settings lets you start tasks, including objectives, on this device from the web app and control their terminals. You can also approve plans and tool requests in any permission mode. Runs started from the web now appear in the Task App's active sessions with a globe marker.
- **Discuss button on every card.** A chat icon next to Start opens the task's chat. You pick the model in the chat's start panel.
- **Chinese and Spanish interfaces.** The Task App is now fully available in Simplified Chinese and Spanish, alongside English and Ukrainian.
- **Scoped Cowboy-Coding mode.** Choose between Disabled, Related Tasks Only and Whole Project. Each follow-up task starts in a fresh session. You can also set the scope for many tasks at once from the bulk action bar. Enabling it still requires Bypass.

## Improvements

- Objective tasks now have a regular Start. The agent researches and prepares the objective, saves subtasks if needed, then runs them one at a time.
- The bulk action bar has a **Model** picker next to the agent picker. Every bulk agent change now saves a model the agent actually offers.
- Sprint headers have a select-all control and a Start action, replacing the lone Start button.
- Dependency keys of completed or canceled tasks are struck through on cards, in task forms and in chat proposals.
- Images in task and project chats now appear inline where you inserted them. Pasting or dropping another image goes in at the cursor.
- Cmd+S (macOS) or Ctrl+S saves and closes the Task Edit modal.
- A new **My Active Tasks** section in the left menu lists your in-progress human tasks.
- New sprints, and existing undated sprints that receive tasks, now get forecast dates automatically. Dates you set manually are kept.
- Branches and pull requests published by merges are recorded as development links on their tasks.
- The web app's Model field now suggests the models actually installed on your devices, instead of a fixed list.
- On macOS, startup now asks for Screen Recording and Accessibility when they are off, and offers optional App Management setup guidance. One prompt names only what is missing, and you can choose Don't Ask Again.
- Notification registration Repair now verifies its result. It tells you when an installer disk needs ejecting or other app copies remain.
- Ukrainian product terminology has been standardized.

## Fixes

- Long card titles always start at their first letter and end with an ellipsis, instead of scrolling away on hover.
- Card controls fit on one row on narrow cards. The controls row and the card actions menu close when the cursor leaves after a click.
- Focusing or expanding a card no longer locks board scrolling.
- Start buttons, including Start on dependent tasks, update right after you save a task. No board reload is needed.
- When a Codex task names no model and the inherited Codex setting points to a model that is no longer served, the run uses a currently available model.
- Objective parents stay visible on the board when objective grouping is off.
- Completion checkmarks in the active sessions list no longer disappear after a slow board refresh.
- The Open Project chooser stays usable when a task modal is open.
- Boards for projects without Git no longer repeatedly request merge status.
- Agent terminal activity no longer takes keyboard control back from a web viewer.
- Devices now come online for remote control even when a project was configured before device IDs existed or was opened only in a desktop window.
- Runs are attributed to the correct machine.
- Tasks left claimed by a device after a quit, crash or update are released automatically.
- Signing out or switching accounts immediately ends remote access granted under the previous account.
- The browser launch-code login form works again.
- Project chat uses architecture documentation tools more reliably.

## Upgrade notes

- Remote control is now confirmed per device, account and local project copy. If you enabled it earlier by editing project settings, it stays off until you turn on **Allow remote control** again in Project Settings. Signing out or switching accounts also requires confirming it again.
- The project-level device ID setting is no longer used. Each machine now identifies itself automatically.
- Computer use requires Screen Recording and Accessibility permissions on macOS. You can grant them from the startup prompt or later in System Settings.
