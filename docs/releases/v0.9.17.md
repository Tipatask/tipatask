## Highlights

- **Agent permission modes.** Choose how much freedom a coding agent gets on each task: **Plan** (the agent plans first and implements after you approve), **Auto** (the agent asks only when unsure) or **Bypass** (no approval prompts; the task runs unattended). Set a project-wide default under Project Settings → Workflow → Agent permissions, and override it per task in the Task Edit dialog.
- **Image-generation tasks with OpenRouter.** Add an OpenRouter image model in the model form and assign it to a task. The task description becomes the prompt, and the images are saved to a folder in your project.
- **Objectives keep their source material.** Tasks planned from an objective now keep its links, images, copy text, example values and data hints, so nothing from your original request is lost along the way.
- **Banner clicks bring the app forward on macOS.** Clicking a card on the always-on-top banner now shows the project window even when it is on another desktop (Space) or behind a full-screen app.

## Improvements

- Each task card shows a shield icon for its effective permission mode. Hover it to see the mode, or click it to open Task Edit with the permission field focused.
- Running sessions in the side rail show the same shield next to the agent icon, including when the rail is collapsed.
- The terminal header shows which permission mode a run uses and whether it came from the project default. The mode is fixed when a run starts, and changes take effect on the next run.
- If an agent can't run in the chosen permission mode, the task doesn't start and the terminal explains why.
- Plan mode works the way it did before. The agent presents a plan, waits for your approval, then carries on in the same session. You can approve from the Task App or directly in the agent's own terminal dialog.
- Claude Code uses its built-in permission prompts again, and tasks start faster as a result. Bypass runs no longer stop at Claude's extra confirmation screen.
- Design Mode now works with any permission mode.
- In Bypass mode, agents make sensible decisions on their own instead of stopping to ask routine preference questions. They still ask when information is genuinely missing or when you request a consultation.
- **Image model settings:**
  - The model form has a Text or Image purpose choice, OpenRouter image model suggestions, aspect ratio, image count and an output folder.
  - Each image task sends a single generation request, with no automatic paid retries.
  - Image models are left out of the text-chat and planning model lists.
- When an objective becomes a single task, that task is treated as the full specification. Every link, image and detail from the objective counts as a requirement.
- If a generated task leaves out a design link or image reference from your objective, it is added back to the task description when you save.
- Project preferences now come from your signed-in account. The project creator sets the shared defaults, and other members keep their own personal settings. A local copy is kept per account and server, and it never contains credentials.
- All text on completed task cards is now an evenly muted grey, so finished work is easier to tell apart while staying readable in every theme.

## Fixes

- The New Objective conversation now scrolls to the latest message whenever a new one arrives, instead of jumping back to the top.
- The permission mode menu is no longer cut off in a short Task Edit dialog.
- Fixed tasks sometimes missing from the board, and running sessions showing an outdated completion status in the side rail.
- Fixed the always-on-top notification banner showing no cards.
- In Plan mode, you can again answer the agent's plan and permission prompts from the keyboard in the terminal.
- Image task buttons now have a clearly visible keyboard focus outline in dark themes.
- Settings → General → Notifications no longer shows an empty yellow hint box with a blank button.
