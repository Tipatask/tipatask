## Highlights

- **Attach images and files to task descriptions.** The task editor's description now has the same Embed button as the chat composers. You can also drop files onto the description or paste images into it. Attachments reach the agent together with the task.
- **Pick several files at once.** The Embed button's Image and Other file pickers now accept multiple files, in the objective chat, the task and project chat, and the task description.
- **Links in terminals work again.** Confirmed links from task terminals now open in your default browser. Plain web addresses printed by an agent in a task terminal or the objective console are now clickable too.

## Improvements

- When you pick several files for a task description while the editor is closed, each attachment goes on its own line. With the editor open, attachments are inserted at the cursor.
- Save, Cmd/Ctrl+S, Start and Stop in the task editor now wait for attachments that are still uploading. If an upload doesn't finish, you're told it was left out of the description.
- In the task chat, Send waits until every file in a multi-file pick has finished uploading.
- Agents can now set, change or clear a task's severity through the task tools, and task lists include it. Updating a task without mentioning severity keeps the severity it already has.
- The README now has a short demo of the app and a step-by-step guide for the installed app, from opening a project to running and reviewing your first task.
- The README's download table now lists the Linux AppImage as x64 with glibc 2.35 or newer. It also links to install and sign-in guides for the Claude and Codex command-line tools.

## Fixes

- Fixed confirmed terminal links failing with "Could not open the link." The same fix restores opening attachment files, the debug log's Reveal button, and the macOS Notifications Settings button.
