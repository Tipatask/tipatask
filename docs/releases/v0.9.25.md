## Highlights

- **Attach images and files to task descriptions.** The Task Edit description has the same Embed control as the chat composers. You can pick images or other files, drop files onto the description, or paste images into the editor. Attachments reach the agent together with the task.
- **Pick several files at once.** The Embed pickers accept multiple files in the objective chat, the task and project chat, and the task description.
- **Clickable links in terminals.** Plain web addresses printed in task terminals and the objective console are now clickable, and confirmed links open in your default browser.

## Improvements

- Save, Cmd/Ctrl+S, Start and Stop in the Task Edit window wait for attachments that are still uploading. If an attachment doesn't finish uploading, it is left out of the description and you are told.
- When several files are attached to a closed description, each one goes on its own line.
- In the task chat, Send waits until every file in a multi-file pick has uploaded.
- Agents can now set, clear and read a task's severity through the app's task tools. Editing a task without mentioning severity no longer clears an existing value.
- The README now includes a short demo of the app and a step-by-step guide for the installed app, from opening a project to running and reviewing your first task.

## Fixes

- Fixed "Could not open the link" appearing every time a confirmed terminal link was opened.
- The same fix restores several other actions that had silently failed: opening attachment files, the debug log's Reveal button, and the macOS Notifications Settings button.
