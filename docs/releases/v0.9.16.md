## Highlights

- **Windows upgrades work again.** Installing over an earlier version no longer fails with "TipATask cannot be closed" when nothing is running. Setup also replaces older installations cleanly and closes a running app more reliably.
- **Pi tasks start on Windows.** The startup check no longer times out on a cold start or on slower machines. If the bundled runtime can't be used, it falls back to an installed Node.js. When the check does fail, the message says which step failed and how long it took.
- **Codex tasks on Windows receive their kickoff reliably.** The app now waits until Codex has finished starting before it submits the task prompt. If the prompt gets stuck in the input box, the app retries it.
- **A steadier board.** Scroll position and the open card are kept across background refreshes, and the board no longer shifts while you drag a card.
- **Safer quitting on Windows and Linux.** Closing the last window now asks before quitting. Cancel keeps the window and its sessions open.

## Improvements

- Windows installers are now available for both x64 and ARM64. Each includes the matching task terminal runtime.
- Claude's folder-trust prompt is pre-accepted for your projects, so a project's first Claude task goes straight to work.
- The planner now explains when it proposes no task changes, or when its proposed cards were rejected (for example, because the target tasks are locked). Before, these cases were treated as failures or retried automatically.
- Clearer messages when the planner returns an empty or unreadable response.
- When you answer a question dialog in a task or project chat, the answer now appears on the dialog only, not repeated as a separate chat bubble.
- When Pi is unavailable, the agent picker shows what was tried and what the check reported.

## Fixes

- Starting a task from the edit dialog with a saved Pi model no longer reopens the agent picker.
- On the Backlog tab and on the board with Sprints turned off, a card no longer disappears after a status change until the next refresh.
- In the desktop app, active board filters and the Backlog count now update right after you confirm a status change.
- An open card stays in place when its task is updated or moves to another sprint, without leaving gaps or leftover overlays behind.
- Hover-opened cards no longer briefly collapse and reopen during refreshes. Cards with running sessions no longer re-animate their controls on every refresh.
- After a failed Claude chat turn, the question dialog reopens so you can answer again, and any text you typed is returned to the input box.
- Codex sign-in now works on Windows systems that don't allow symbolic links. Credentials are copied and kept up to date.
- Codex usage limits are now read correctly on Windows.
- Pi task prompts on Windows keep their quotes and line breaks, and long prompts no longer exceed command-length limits.
- Cancelling the quit dialog on Windows no longer leaves a hidden app running in the background that blocked the next launch.
